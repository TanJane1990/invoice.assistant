# 智能发票管理助手 (Smart Invoice Assistant)

一个高效、专业的电子发票批量解析、智能拼页排版打印、发票台账管理与自动报销封面生成工具。支持 Windows (Win 7/10/11) 和 macOS 跨平台使用。

---

## 🌟 核心功能

### 1. 📄 智能拼页排版与打印预览
- **多排版模式**：支持 **1张/页 (单张原票 210×140mm)**、**2张/页 (上下纵向)**、**4张/页 (2×2 宫格)** 自由切换。
- **辅助打印设置**：可开启/关闭 **打印剪切线**、**打印报销封面**，并支持自定义页边距（紧凑/适中/宽松）。
- **极简初始化界面**：软件启动时保持干净清爽的预览状态，导入或勾选发票后自动高精排版。

### 2. 📑 发票台账与防重复报销 (查重)
- **历史台账留存**：自动保存历史录入的发票记录，防止误删与丢失。
- **自动查重校验**：导入新发票时，自动匹配发票代码与发票号码，精准提示是否重复报销。
- **按最新时间排序**：新导入或识别的发票自动置顶显示在台账最上方，方便实时核对。
- **一键导出 Excel**：可将完整发票台账数据一键导出为标准 Excel 表格文件。

### 3. 📝 报销汇总封面单
- **自动汇总与生成**：根据已选发票自动汇总发票张数、价税合计金额。
- **大写金额自动转换**：自动将人民币金额转换为标准中文大写金额（如：壹仟贰佰叁拾肆元整）。
- **独立打印/附带打印**：可作为独立报销封面打印，也可随发票排版一并连打。

### 4. 🚀 多引擎智能解析与识别
- **PDF 与图片双支持**：支持拖拽或批量导入电子发票 PDF 文件及发票拍照图片。
- **内置本地 PDF 解析**：直接提取 PDF 中的发票矢量文字与元数据，无须依赖外部 API。
- **AI 大模型 / 云端 OCR 识别**：支持配置 API Key 快速解析图片格式发票。

## ⚡ 性能与兼容性专项优化 (Win 7 / 10 / 11 & macOS)

为了保证在低配 Windows 7 机械硬盘和最新 macOS / Win 11 上都具备极速极致体验，软件集成了以下核心架构优化：

1. **🔒 锁死 Electron 22.x 版本**：Chromium 在 Chrome 109 之后停止对 Win7 的支持，本项目严格锁定使用 Electron `22.3.27` 版本，完美原生兼容 Windows 7（同时支持 32 位 `ia32` 与 64 位 `x64`）、Windows 10/11 及 macOS。
2. **⚡ 按需动态加载 PDF 解析库**：取消启动时的全局同步加载，改为在拖入/打开发票时通过动态 `import()` 延迟加载 PDF 模块，**缩短 30%+ 软件首屏启动时间**。
3. **🖼️ 窗口防白屏闪烁优化**：Electron 窗口创建时默认 `show: false` 并预置优雅背景色 `#f8fafc`，在 DOM 绘制与内容渲染完成后通过 `ready-to-show` 一次性显现，彻底消除启动时的白色闪屏。
4. **📦 极简包体积与禁用硬件加速**：针对 Win7 老旧显卡配置了 `disableHardwareAcceleration()` 防止显卡卡死/黑屏，并在 `electron-builder.json` 中配置最高阶 Asar 压缩打包，显著降低机械硬盘读取延迟。

## 💻 本地运行与开发

### 1. 克隆/解压源码
下载解压项目源码后，在项目根目录打开终端。

### 2. 安装依赖
```bash
npm install
```

### 3. 启动本地开发服务
```bash
npm run dev
```
打开浏览器访问 `http://localhost:3000` 即可开始使用。

### 4. 构建 Web 生产包
```bash
npm run build
```
打包生成产物将存放于 `dist/` 目录。

## 📦 桌面端打包指南 (Windows & macOS)

本项目已内置 `electron-builder.json` 配置文件及 `.github/workflows/build-desktop.yml` 自动打包脚本。

### 方式一：利用 GitHub Actions 自动云打包（推荐）
1. 将源码导出并推送到你的 GitHub 仓库。
2. 访问仓库的 **Actions** 标签页。
3. 触发 **Build Desktop App** 工作流，运行完成后即可在 Artifacts 中直接下载编译好的 **Windows (.exe 安装包)** 和 **macOS (.dmg 安装包)**。

### 方式二：本地执行 Electron 打包
在本地环境中安装 Electron 打包工具：
```bash
# 1. 安装打包工具
npm install --save-dev electron electron-builder

# 2. 执行打包指令
npx electron-builder
```
打包完成后，安装包文件将生成在 `dist_electron/` 目录下。

## 🔒 隐私与数据安全

- 本系统所有发票台账数据均存储于本地浏览器/客户端缓存（`LocalStorage`）中，不会上传至任何第三方未经授权的服务器。
- 本地 PDF 发票解析全部在客户端本地完成，保障公司财务与个人报销数据安全。
